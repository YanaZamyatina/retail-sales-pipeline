# Retail Sales Pipeline

Проект предназначен для автоматической генерации данных о продажах ритейл-магазина и их последующей загрузки в базу данных **PostgreSQL** по расписанию Windows.

## Структура проекта
* `data/` — папка, в которую генерируются временные CSV-файлы продаж.
* `config.ini` — файл конфигурации с путями и доступами к БД.
* `create_table.sql` — SQL-скрипт для инициализации структуры таблицы `sales` в БД.
* `generate_sales_data.py` — скрипт для генерации фейковых данных о продажах.
* `pgdb.py` — модуль с классом `PGDatabase` для работы с PostgreSQL.
* `upload_sales_data.py` — основной скрипт обработки файлов и загрузки данных в БД.
* `generate_data.bat` и `upload_data.bat` — батники для автоматического запуска скриптов.
* `requirements.txt` — список необходимых внешних библиотек для работы проекта.

## Пошаговая инструкция по развертыванию

### Шаг 1. Клонирование и подготовка окружения
1. Перенесите папку проекта `retail-sales-pipeline` на новую машину.
2. Откройте терминал в папке проекта и создайте виртуальное окружение **venv**:
   ```bash
   python -m venv venv
   ```
3. Активируйте виртуальное окружение:
   * _Windows (cmd)_: `venv\Scripts\activate.bat`
   * _Windows (PowerShell)_: `.\venv\Scripts\Activate.ps1`
4. Установите все необходимые библиотеки из файла зависимостей:
   ```bash
   pip install -r requirements.txt
   ```

### Шаг 2. Настройка базы данных
1. Подключитесь к вашему серверу **PostgreSQL** через любой удобный клиент (например, DBeaver).
2. Создайте целевую базу данных.
3. Откройте и выполните код из файла `create_table.sql`, чтобы создать таблицу `sales`.

### Шаг 3. Заполнение конфигурации
Создайте или отредактируйте файл `config.ini` в корне проекта. Пример заполнения:
```ini
[Files]
SALES_DIR = ./data
FILE_MASK = *_*.csv

[Database]
HOST = localhost
DATABASE = your_db_name
USER = your_username
PASSWORD = your_password
```

## Автоматизация (Планировщик Windows)

### 1. Подготовка батников
Перед настройкой автоматизации откройте ваши `.bat` файлы через текстовый редактор и пропишите в них **свои актуальные абсолютные пути** к интерпретатору Python внутри venv и к самим скриптам:

* В файл `generate_data.bat` вставьте строку:
  ```text
  "C:\путь_к_проекту\retail-sales-pipeline\venv\Scripts\python.exe" "C:\путь_к_проекту\retail-sales-pipeline\generate_sales_data.py"
  ```
* В файл `upload_data.bat` вставьте строку:
  ```text
  "C:\путь_к_проекту\retail-sales-pipeline\venv\Scripts\python.exe" "C:\путь_к_проекту\retail-sales-pipeline\upload_sales_data.py"
  ```

### 2. Настройка задач
Создайте две задачи с необходимыми параметрами (например, повторение: Еженедельно, дни: Пн, Вт, Ср, Чт, Пт, Сб, воскресенье — пропустить):

1. **Генерация данных** (например, запуск в 20:05):
   * _Действие_: Запуск программы.
   * _Программа или сценарий_: Полный путь к вашему файлу `generate_data.bat`
   * _Рабочая папка (Start in):_ Полный путь к папке проекта на вашей машине: `C:\путь_к_проекту\retail-sales-pipeline\`

2. **Загрузка в БД** (например, запуск в 20:10):
   * _Действие:_ Запуск программы.
   * _Программа или сценарий:_ Полный путь к вашему файлу `upload_data.bat`
   * _Рабочая папка (Start in):_ Полный путь к папке проекта на вашей машине: `C:\путь_к_проекту\retail-sales-pipeline\`
